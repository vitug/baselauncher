# BaseLauncher — руководство пользователя

BaseLauncher — замена SM 1.4: список ваших баз 1С (тот же `ibases.v8i`, что читает 1С), запуск в Предприятие/Конфигуратор, настройки, обслуживание кэшей и платформ. Работает в собственном окне (Edge `--app`), сервер — локально на вашей машине.

## Запуск и окно

- Автозапуск с Windows — `pythonw boot.py` (сервер + окно). Ярлык «Пуск» — тот же запуск.
- **Ctrl+Shift+S** — показать/спрятать окно из любого места (то же — клик по иконке в трее; правый клик по трее — меню «Показать/Скрыть/Открыть в браузере/Выход»).
- Повторный запуск не создаёт второе окно — поднимается существующее.
- Размер и положение окна запоминаются.
- Полный выход — правый клик по трей-иконке → «Выход» (перезапуск/закрытие — внизу строки состояния).

## Список баз

- Дерево папок = ваше `ibases.v8i`; папки по умолчанию свёрнуты, раскрытые запоминаются.
- **Один клик по строке — выбор, двойной клик — запуск** (так же работают Enter и все вкладки).
- Вкладки над списком: **Все · ★ Избранное · ● Открытые · ⟲ Недавние** (Ctrl+1…4). Каждая помнит свою позицию прокрутки.
- В строке базы:
  - `●` — база открыта сейчас; `◷` — свежий запуск (синий — сегодня, жёлтый — вчера);
  - `П`/`К` — режим по умолчанию (клик по метке циклит ⇢→К→П; двойной клик по метке базу не запускает);
  - кнопки: `⚙` настройки · `🌐` веб-база в браузере · `Конф` · `Предпр` · `cmd` (показать строку запуска);
  - `★` — в избранное; `⧉` — копирование реквизитов (имя, путь, Srvr/Ref, строка соединения).
- Поиск сверху: фильтрует на лету, история запросов; `Esc`/`✕ фильтр` — сброс с возвратом к выделенной строке.
- Фильтры шапки — тумблеры: `⚠ проблемы`, `8.3`, `8.5` (повторный клик снимает).
- Перетаскивание базы в папку — с подтверждением (меняется `Folder=` в `ibases.v8i`, сама база на диске не трогается).
- Правый клик по строке — полное меню: запуск, кэш (3 вида), COM, .dt, копирование, удаление из списка, настройки.

## Запуск базы

- Режим: кнопка `Конф`/`Предпр`, метка `П/К` или режим из шапки (⇢ — «как у базы»).
- Перед запуском сервер проверяет соединение (сервер/файл/веб) и показывает понятную причину, если что-то не так; «Запустить всё равно» — обход проверки.
- Если база уже открыта — предлагается переключиться на её окно (у сеансов без окна, например из EDT, честно пишется «нет окна»).
- Платформа: АВТО (по `Version=` из ibases.v8i, ver-файлу хранилища, формату 1CD) или закреплённая в настройках базы. После неудачного запуска лаунчер сам пробует подходящие платформы и закрепляет рабочую.
- Если платформы нет — диалог предложит поставить с шары, открыть папку дистрибутивов или заменить на ближайшую.
- Разовые ключи: панель в шапке — ключи запуска, обработка `/Execute` (выбор файла через `…`), `WS`/`Thin` и т.п. В конфиг не пишутся.

## Настройки базы (⚙ или Alt+Enter)

Имя, описание, учётки и пароли (раздельно для Предприятия и Конфигуратора), платформа (АВТО/конкретная, списком по семействам, с конфигуратором сверху), режим по умолчанию, избранное, папка, хранилище конфигурации, доп. ключи. Пароли хранятся в своём конфиге лаунчера (`data/config.json`) в обфускации — «защита от дурака», не криптография. В интерфейсе пароли не показываются — только «пароль сохранён».

## Кэш 1С — три уровня

У каждой базы (по GUID из `ibases.v8i`):

| Уровень | Где | Что внутри | Что будет при очистке |
|---|---|---|---|
| **Кэш программы (конфигурации)** | `%LOCALAPPDATA%\1C\1cv8\<guid>` | Config, ConfigSave, SICache, cgf-cache, cfgrepo, КэшМодулей/Ролей | Пересоздаётся сам; лечит «битый» кэш |
| **Настройки пользователя** | `%APPDATA%\1C\1cv8\<guid>` | 1cv8.pfl, def.usr — окна, формы, интерфейс | Сбрасывает интерфейсные настройки |
| **Общий (для всех пользователей ПК)** | `%PROGRAMDATA%\1C\1cv8\<guid>` | общий кэш | Обычно пуст |

Пункты — в контекстном меню базы (по уровню) и в меню ☰: «Очистить кэш по базам (выбрать)» — окно с чекбоксами, поиском, «выбрать всё / снять всё / переключить выбор», типом кэша (config/user/оба) и суммой освобождаемого места.

## Меню ☰ (обслуживание, правый край шапки)

- **Платформы: список** — все установленные платформы: версия, семейство, разрядность, размер, компоненты (конфигуратор / тонкий клиент / сервер / COM), кто на ней сидит. С кнопок: перевести базы…, открыть папку, удалить.
- **Удалить ненужные платформы (выбрать)** — чекбоксы; платформы с базами или живыми сеансами заблокированы (с подсказкой); удаление из Program Files — через UAC.
- **Перевести базы на другую платформу** — фильтр «откуда» (семейство или точная версия), **фильтр по конкретным хранилищам** из данных баз (одно хранилище = несколько баз, выбираются разом; есть «без хранилища»; в список попадают только реальные хранилища — UNC-пути `\\…`, локальные `D:\…` и серверные `tcp://…`), поиск, чекбоксы, выбрать/снять/переключить, колонки `Version=` и «по хранилищу» (версия по ver-файлу). Перевод закрепляет exe в настройках и пишет `Version=` в `ibases.v8i` — базу откроет и штатный лаунчер 1С.
- **Мёртвые кэши** — каталоги кэша без живой базы (остались от удалённых): чекбоксы, поиск по GUID, размер/дата, удаление выбранных. Данные баз не затрагиваются.
- **Кэш пользователя 1С (все базы)** — суммарная очистка по всем базам.

## Что делать при проблемах

- «Ничего не произошло» при запуске — смотрите строку состояния внизу: там причина (предпроверка, платформа, «нет окна»).
- База «странно» себя ведёт — очистите кэш программы этой базы (контекстное меню).
- Окно потерялось — Ctrl+Shift+S.
- `cmd` у строки — покажет точную команду запуска (пароль замаскирован).
