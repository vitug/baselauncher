# BaseLauncher.exe — запуск exe-сборки

Однофайловая сборка `BaseLauncher.exe` (PyInstaller onefile, ~16 МБ). Python и
какие-либо пакеты на машине **не нужны**. Нужен только установленный клиент 1С.

## Где взять

- Репозиторий: `dist_exe/BaseLauncher.exe` (собран из master, см. git log);
- сборка: чистый venv + `pyinstaller --onefile --noconsole --icon assets/baselauncher.ico
  --add-data "app/static;app/static" --add-data "assets;assets" --hidden-import app.main
  run_server.py`.

## Установка

1. Создайте папку, например `C:\BaseLauncher\`, и скопируйте туда `BaseLauncher.exe`.
2. Запустите exe двойным кликом.

При первом запуске (каждый старт onefile-архива распаковывается 5–10 секунд —
это нормально) сервер поднимется на **http://127.0.0.1:8797** и откроется окно
в браузере. Рядом с exe появится папка `data\`:

```
C:\BaseLauncher\
├── BaseLauncher.exe
└── data\
    ├── config.json      настройки (по умолчанию пустые)
    ├── server.log       лог сервера
    ├── audit.log        журнал действий
    └── ...
```

## Источник списка баз

Базы читаются из стандартного списка 1С:
`%APPDATA%\1C\1CEStart\ibases.v8i` — тот же, что видит стартер 1С. Ничего
переносить не нужно: если базы есть в списке 1С, они появятся в ланчере.

## Автозапуск

Ярлык на `BaseLauncher.exe` положите в `shell:startup` (Win+R → `shell:startup`).
Трей-иконка и глобальная клавиша **Ctrl+Shift+S** работают и в exe-сборке.

## Параметры (переменные окружения)

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `BL_PORT` | `8797` | порт сервера |
| `BL_DATA` | `<папка exe>\data` | каталог данных (конфиг, логи) |
| `BL_IBASES` | `%APPDATA%\1C\1CEStart\ibases.v8i` | путь к списку баз |
| `BL_SHARE` | из `data/config.json` (`share_root`) | корень шары платформ |
| `BL_DEV` | — | `1` = без трея и глобальной клавиши (второй инстанс) |

Пример запуска второго экземпляра на другом порту:
`cmd: set BL_PORT=8801&& set BL_DATA=C:\bl2\data&& BaseLauncher.exe`

## Перезапуск из интерфейса

Кнопка «Перезапуск» в UI в exe-сборке перезапускает сам exe: старый процесс
закрывается, новый ждёт освобождения порта (`--wait-down`) и поднимается.

## Ограничения exe-сборки

- `mcp_server.py` в exe не входит (MCP-интерфейс — только в zip-поставке с Python);
- первый запуск каждого старта — распаковка 5–10 сек;
- при переносе на другую машину настройки баз берутся из её же `ibases.v8i`,
  а файловые базы должны существовать по своим путям.

## Остановка

- Из UI: кнопка выключения/«Перезапуск»;
- из командной строки: `curl -X POST http://127.0.0.1:8797/api/shutdown`;
- просто закрыть процесс тоже можно (воркеров-сирот exe не оставляет).
