Выгрузить конфигурации в XML

Конфигурация каждой выбранной файловой базы выгружается в свой подкаталог (ibcmd, формат платформы базы). Открытые базы пропускаются — закройте их сеансы.

Загрузить конфигурации из XML

Исходники каждой базы ищутся в root\<имя базы> (как раскладывает «Выгрузить конфигурации в XML…»), иначе грузится сам root. Полная загрузка ЗАМЕНЯЕТ всю конфигурацию базы.

Настройки базы

Вход в базу
Хранится в своём конфиге data/config.json не открытым текстом (обфускация «от дурака»). Пароль показывается расшифрованным — поменяйте поле и сохраните. Пустое поле = входить без пароля. Пустой пользователь Конфигуратора = как в Предприятии.

Платформа
Тонкий клиент (1cv8c.exe, если есть у выбранной платформы)
Хранилище конфигурации (подключается в конфигураторе)
Ключи конфигуратора: /ConfigurationRepositoryF /N /P.
