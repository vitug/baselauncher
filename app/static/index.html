Добавить

Пишется в ibases.v8i (бэкап файла делается автоматически раз в день); база сразу появится и в штатном лаунчере 1С.

Настройки базы

Пароль хранится локально в data/overrides.json открытым текстом (пароль из SM не переносится — он зашифрован).
Платформа
Тонкий клиент (1cv8c.exe, если есть у выбранной платформы)
Хранилище конфигурации (подключается в конфигураторе)
Ключи конфигуратора: /ConfigurationRepositoryF /N /P.
Режим запуска по умолчанию
С ним база запускается по клику на строку. Кнопки «Предпр»/«Конф» всегда запускают свой режим.
