# BaseLauncher

Свой аналог SM 1.4: список баз 1С (импорт из ibases.v8i + настроек SM)
и запуск выбранной платформой. Веб-UI на FastAPI — отладка в браузере (DevTools).

## Запуск

```bash
D:/python/WPy64-31241/python-3.12.4.amd64/python.exe run_server.py
# → http://127.0.0.1:8797
```

Или двойным кликом `start_bl.bat`: проверяет сервер, при необходимости поднимает его
в отдельном свёрнутом окне и открывает приложение в окне Edge (`--app`, без адресной строки).

Порт — из `BL_PORT` (по умолчанию **8797**). Не 8790/8796: там остались python-воркеры
убитых сессий (kill бьёт bash-обёртку, uvicorn-ребёнок переживает и держит порт); 8791 —
вотчер моделей. Биндинг поверх занятого порта на этом хосте даёт `WinError 10048/10013`,
а не «нет прав» — при такой ошибке первым делом проверяй занятость порта.

**Останавливать сервер — `POST /api/shutdown`, а не kill сессии**: тогда порт освобождается
и сирота не остаётся. uvicorn-reload по умолчанию выключен (стабильность); для разработки —
`BL_RELOAD=1`.

## Структура

- `core/` — логика на чистом stdlib (движко-независимая):
  - `parsers.py` — ibases.v8i, v8config.smc, settings.cnf (форматы разведаны реверсом launcher.exe);
  - `scanner.py` — поиск платформ в Program Files и `D:\storage1C\ПлатформаКвас`;
  - `launcher.py` — сборка команды СТРОКОЙ (`/IBConnectionString` из Connect) + Popen + лог и
    сводка истории запусков (`history()`);
  - `v8i_writer.py` — запись в `ibases.v8i`: добавление базы/папки, удаление секции;
  - `procs.py` — живые сеансы 1С (`ctypes`): PID, режим, база из командной строки, активация окна;
  - `importer.py` — слияние источников → `data/bases.json`.
- `app/main.py` — REST: `GET /api/state`, `GET|PUT|DELETE /api/base/{guid}`,
  `POST /api/base/new|/api/folder/new`,
  `POST /api/launch|/api/dryrun`, `POST /api/activate`, `GET /api/log`, `POST /api/shutdown`.
- `app/static/index.html` — UI без зависимостей: дерево папок как в SM, режимы
  Предприятие/Конфигуратор, избранное, поиск, разовые ключи запуска.
- `data/overrides.json` — свои правки поверх импорта (высший приоритет).
- `start_bl.bat` — стартер: сервер + отдельное окно приложения.

## Важно: командная строка 1С — строкой, не списком

1С парсит `/IBConnectionString` не по правилам CRT. `Popen(list)` заэкранирует кавычки
(`File=\"...\"`) → 1С покажет LocalFileAccessError «Неправильный путь к файлу '1Cv8.cdn'.
Схема не зарегистрирована». Поэтому `build_cmd()` возвращает строку с литеральными
кавычками (как SM), и `Popen(строка)`.

## Проверки наличия (v0.4.0)

В состоянии каждой базы (`GET /api/state`) и в UI:

- **папка базы** — файловые: существует ли каталог и файл базы (`1Cv8.1CD`) внутри; серверные
  не проверяются (`path_ok: null`, «серверная»);
- **exe платформы** — существует ли разрешённый exe на диске (`exe_ok`);
- в строке базы — красные метки `✖папка` / `✖exe`, в шапке — чип `⚠ проблемы (N)` (фильтр
  только проблемных), в статус-строке — счётчики «нет папки / нет exe»;
- `POST /api/launch` перепроверяет наличие свежими `is_dir()`/`is_file()` и возвращает 400
  с конкретным путём — вместо непонятного окна 1С или падения `Popen`.

## Добавление баз и папок (v0.5.0)

Кнопки **«+ база»** и **«+ папка»** в шапке. Пишется не в свой `data/bases.json`,
а в тот же файл, что читает 1С: `%APPDATA%\1C\1CEStart\ibases.v8i` — база сразу
появляется и в штатном лаунчере 1С, и в BaseLauncher.

- база: имя, папка дерева, тип — файловая (путь к каталогу → `Connect=File="…"`) или
  серверная (сервер + имя базы → `Connect=Srvr="…";Ref="…"`), `App=Auto`;
- папка: имя + родитель (секция без `Connect=`, `OrderInList=-1`, `Folder=<родитель>`);
- уникальность имён проверяется (регистронезависимо), новый элемент встаёт первым
  в своей папке (`OrderInTree = max+1024`);
- «Удалить из ibases.v8i» в редакторе ⚙ (с подтверждением; непустую папку удалить нельзя);
- REST: `POST /api/base/new {name, folder, path | server+ref}`, `POST /api/folder/new
  {name, parent}`, `DELETE /api/base/{guid}`.

**Как пишем (файл живой, его держит 1С):**

- тело новой секции берётся шаблоном из самого файла (у 1С там смешанные окончания
  строк `\r\r\n` и свои ключи `App/WA/DisableLocalSpeechToText`) — дописывается
  в конец, существующие байты не переформатируются; удаление вырезает ровно диапазон секции;
- кодировка UTF-8 с BOM, как пишет 1С; запись через временный файл + `os.replace`;
- бэкап `ibases.v8i.bak-YYYYMMDD` — один раз в день, до первой правки;
- проверено живьём: добавленная секция находится 1С по `/IBName`, база открывается;
  после добавления и удаления тестовой базы/папки sha256 файла совпадает с исходным.

## Настройки базы (редактор, как в SM)

Кнопка ⚙ в строке базы. Хранится в `data/overrides.json`; эффективное значение =
наше || из SM:

- имя, описание;
- пользователь ИБ (`/N`) и пароль ИБ (`/P` — только свой: из SM не переносится,
  он зашифрован crypto-module);
- платформа (exe из списка найденных) и тонкий клиент (`1cv8c.exe`);
- **режим запуска по умолчанию** (`предпр` / `конф`): с ним база запускается по клику на строку;
  если не задан — используется переключатель в шапке. Кнопки `Предпр`/`Конф` всегда запускают
  свой режим. В списке режима базы показывается метка `П` / `К`;
- хранилище конфигурации: путь / пользователь / пароль — ключи конфигуратора
  `/ConfigurationRepositoryF/N/P` (подключаются в режиме конфигуратора);
- избранное (★). «Сбросить свои настройки» — вернуться к SM/авто.

Ключи запуска (`/Debug`, `/DisableStartupMessages`, `/DisableStartupDialogs`,
`/RunModeOrdinaryApplication`, `/AllowExecuteScheduledJobs`, `/C`) — **разовые**:
выбираются в шапке («разовые ключи») и действуют только на следующий запуск,
в настройках базы не сохраняются.

## История запусков (v0.6.0)

Пишется в `data/launches.log` (JSON-строки: `ts`, `base`, `guid`, `mode`, `pid`, `cmd`).
`GET /api/state` отдаёт готовую сводку:

- `recent` (до 20) — базы по последнему запуску, свежие сверху: `guid`, `name`, `path`, `mode`,
  `last_ts`, `count`, `day` = `today` / `yesterday` / `older`;
- у каждой базы: `last_launch`, `launches` (сколько раз), `launch_day`.

В UI:

- блок **⟲ Недавние** в начале дерева (сворачивается, как папки): одна строка на базу, метка
  «сегодня 12:13 · ×7», кнопки `Предпр` / `Конф` — клик по строке запускает в текущем режиме;
- в дереве базы, запускавшиеся сегодня, подсвечены зелёной точкой ● и фоном строки, вчерашние —
  жёлтой; в статус-строке счётчик «запускалось сегодня: N · вчера: M».

Сводка строится по `guid`; старые записи без `guid` привязываются по имени, если имя в списке
однозначно (поэтому переименование базы в настройках «теряет» её давнюю историю — только давнюю).

## Живые сеансы и переключение (v0.8.0)

`core/procs.py` (stdlib + ctypes) находит клиентские процессы `1cv8/1cv8c/1cv8s`, читает их
командную строку (`NtQueryInformationProcess`, класс 60 — без WMI/PowerShell и без порчи
кириллицы) и определяет базу: `File="…"`, `Srvr="…";Ref="…"`, `/F"…"`, `/IBName"…"`; режим —
наличие `DESIGNER`.

- `GET /api/state` → `sessions` (живые сеансы) и у каждой базы `running`, `running_modes`,
  `running_pids` (режим → PID);
- сверху дерева — блок **● Открытые** (как «Недавние»): открытые базы с метками режимов и PID,
  кнопки `Перекл` (на окно) / `Конф` / `Предпр`; клик по строке — переключение;
- **зелёная точка ●** — только «открыта сейчас» (в дереве и в блоке «Открытые»), свежие запуски
  помечены другим значком **◷** (синий — сегодня, жёлтый — вчера);
- в статус-строке «открыто: N»;
- `POST /api/launch` при уже открытом **том же режиме** отвечает `409 {error:"already_running",
  pid}`; UI спрашивает: «Переключиться» / «Открыть ещё раз» (`force: true`) / «Отмена»;
- `POST /api/activate {pid}` — вывод окна наверх (`EnumWindows` + `ShowWindow`/`SetForegroundWindow`
  с `AttachThreadInput`, иначе Windows не отдаёт фокус).

## Приоритет exe платформы для базы

Список платформ в редакторе — дерево по семейству и разрядности: `8.5 · 64 бита (разработка)`,
`8.3 · 64 бита (разработка)`, `8.3 · 32 бита (тонкий клиент)`; внутри группы — по убыванию версии.
64-битные ставятся для разработки, 32-битные — обычно тонкий клиент.

Кнопки в строке базы: `⚙` настройки · `Конф` конфигуратор · `Предпр` предприятие · `cmd` dry-run
(команда без запуска, правая кнопка).

1. `data/overrides.json` → `bases[guid].exe`
2. v8config.smc: `V8UseAppFile=1` + `V8AppFile` (пер-базовый обход из SM)
3. settings.cnf: слот семейства `V8xAppFile` (слот 8.4 = 8.5 на этом хосте)
4. новейшая установленная платформа семейства `default_family` (по умолчанию 8.3)

## Отладка

- Dry-run: кнопка `cmd` в строке базы — показывает точную команду без запуска.
- Лог запусков: `data/launches.log` (JSON-строки) + `GET /api/log`.
- Сервер только на 127.0.0.1.
