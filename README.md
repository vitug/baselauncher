# BaseLauncher

Лёгкий лаунчер баз 1С:Предприятие 8. Читает общий список баз `ibases.v8i`
(его же понимает штатный стартер 1С), показывает дерево с папками и запускает
базы выбранной платформой в режимах **Предприятие / Конфигуратор**.
Веб-интерфейс на FastAPI работает локально — как родное приложение в окне
браузера, с треем и горячими клавишами.

Ядро (`core/`) написано только на стандартной библиотеке Python; веб-часть —
FastAPI + uvicorn, фронтенд — один статический HTML-файл без сборки.

## Возможности

- дерево баз из `ibases.v8i` с папками, избранное, «недавние», живые сеансы;
- режимы Предприятие/Конфигуратор, тонкий/толстый клиент, разовые ключи запуска;
- запуск от администратора (UAC) — разовый, для публикации базы на веб-сервере;
- свои настройки на базу: платформа, логин, пароли ИБ (не открытым текстом),
  подключение к хранилищу конфигурации;
- файловые (`File=`), серверные (`Srvr=`/`Ref=`) и веб-базы (`ws=`);
- поиск по имени/пути/серверу (Ctrl+F), вкладки Ctrl+1…5, Alt+Enter — настройки;
- дерево установленных платформ 1С с версиями и разрядностью, в т.ч. с сетевого
  каталога (BL_SHARE) с установкой оттуда в один клик;
- **Инструменты**: заданные папки (открыть в Проводнике) и скрипты с параметрами;
- диагностика: проверки пути/exe до запуска, сторож «база не открылась»,
  предпроверка соединения, очистка кэша платформы, chdbfl, выгрузка .dt;
- выгрузка/загрузка конфигурации в XML через `ibcmd` (файловые базы);
- COM-подключение и список пользователей информационной базы;
- журнал аудита действий, MCP-сервер для ИИ-агентов, REST API;
- сборка в один exe (PyInstaller, ~16 МБ) для запуска без Python.

## Запуск

```bash
pip install fastapi uvicorn
python run_server.py            # → http://127.0.0.1:8797
```

Требования: Windows, Python 3.10+ (для веб-части), установленный клиент 1С.

Переменные окружения: `BL_PORT` (8797), `BL_DATA` (каталог данных, по умолчанию
`data/` рядом с кодом), `BL_IBASES` (путь к своему `ibases.v8i`), `BL_SHARE`
(сетевой каталог с платформами), `BL_DEV` (dev-режим с автоперезагрузкой).

Документация: `docs/polzovatel.md` (пользователю), `docs/admin.md` (REST/MCP),
`docs/zapusk-exe.md` (сборка и запуск exe).

## Данные и приватность

Все локальные данные (настройки, пароли, история запусков) живут в `data/`
рядом с приложением и не входят в поставку. Пароли хранятся не открытым
текстом: обфускация XOR+b64 с привязкой к машине и пользователю («защита от
дурака»: при копировании конфига на другую машину значения не расшифруются).
Список баз — стандартный `%APPDATA%\1C\1CEStart\ibases.v8i`, правки в нём
аккуратные (бэкап раз в день, без переформатирования файла).
